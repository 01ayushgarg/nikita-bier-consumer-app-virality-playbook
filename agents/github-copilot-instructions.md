Follow the skill rather than improvising from memory:

1. Read [`../SKILL.md`](../SKILL.md) first and use its audit flow, validation ladder and file-reading order.
2. Read [`../references/benchmarks.md`](../references/benchmarks.md) before using any number, metric or benchmark.
3. Load only the reference chapters and templates named by the skill for the user's situation.
4. Cite source IDs from the reference chapters; never attribute uncited claims to Nikita Bier.
5. Label thresholds, worked examples and templates from this repo as "our reading" or "our suggestion" when they are not Nikita Bier's own words.
6. Keep guardrails from [`../references/12-positive-design-and-guardrails.md`](../references/12-positive-design-and-guardrails.md) in every recommendation.
