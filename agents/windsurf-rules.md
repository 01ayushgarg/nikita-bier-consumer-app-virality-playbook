# Windsurf rule: Nikita Bier Consumer App Virality Playbook

Use `SKILL.md` as the source of truth when the user asks for consumer app growth, virality, activation, invite flow, K-factor, share loops, notifications, launch testing, breakout growth, monetization, rumours or platform risk.

Procedure:

1. Open `SKILL.md`.
2. Open `references/benchmarks.md` before using any metric or benchmark.
3. Read the chapters and templates named by `SKILL.md` for the user's rung of the validation ladder.
4. Return the audit format from `SKILL.md`.
5. Cite chapter/source IDs and mark this repo's own thresholds as "our reading" or "our suggestion".
6. Apply the guardrail pass from `references/12-positive-design-and-guardrails.md`.

Keep this adapter thin; update `SKILL.md`, not this rule, when the playbook changes.
